# 00 索引

這份檔案只回答一件事：AI 要去哪裡讀你的背景和專案。

## 固定入口

| 類型 | 檔案 | 用途 |
|---|---|---|
| 我是誰 | `01_我是誰.md` | 身份、工作型態、偏好、禁區 |
| 專案 | `02_專案範本.md` | 每個專案目前做到哪、卡在哪、下一步 |
| 工作規則 | `03_給AI的工作規則.md` | AI 開工前要遵守的規則 |
| 指揮家 | 已安裝的 `vv-conductor` skill | 任務分級、派工、紅黃綠授權、驗收 |
| 老闆視角 | 已安裝的 `vv-conductor` skill | 幫你排今天優先順序 |

前三個檔案是**你自己的**，放在你的記憶庫（預設 `~/vv-memory/`），由你填寫。
後兩項是 vv 的規則，已經在 skill 裡，你不用另外準備。

## AI 開工規則

每次新對話，AI 必須先讀：

1. 本檔。
2. `01_我是誰.md`。
3. 跟本次任務相關的專案檔或 handoff。
4. `03_給AI的工作規則.md`。

讀完第一句要回「記憶訊號」。
